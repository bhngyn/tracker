Tracker · User guide

Collecting social media
with Claude and Apify

Tracker is a kit for collecting public posts from Instagram, Facebook, X, YouTube and other platforms. You tell Claude what you want collected. Claude sets it up, shows you the cost, and runs it once you approve.

Three things the kit does for you

Caps the spendEvery scrape has a hard dollar limit, and a project has a total budget that no set of scrapes can exceed.
Never pays twiceEach scrape is recorded when it starts. After a crash, the same command picks it up again.
Keeps the originalsRaw results are saved unmodified, with a record of when they were collected and what they cost.

Part 1

Set up your Apify account

Apify runs the scrapers and bills you for them. Each person uses their own account, so spending and results stay separate. This takes about five minutes.

  1. Create an account

    Go to console.apify.com/sign-up and sign up with an email address, Google or GitHub. No card is needed for the free plan.

  2. Choose a plan

    The free plan includes a small monthly credit (about $5 at the time of writing). That covers setup and a test of a few hundred posts. For a real project, upgrade to a paid plan under Billing in the console. Paid plans also lower the price per post on some scrapers.

  3. Set a monthly spending limit

    In the console's billing settings, set the maximum you are willing to spend in a month. Apify stops all scraping when it is reached. Tracker has its own caps, and this is the backstop behind them.

  4. Copy your API token

    Open Settings → API & Integrations (console.apify.com/settings/integrations). Under Personal API tokens, copy the default token, or create a new one and name it tracker so you can revoke it on its own later.

    The token is a long string that starts with apify_api_. Keep it on your clipboard for Part 2.

Treat the token like a password. Anyone who has it can spend your Apify credit. Paste it only into the .env file described in Part 2. Don't paste it into a chat with Claude, an email or a shared document. If it is ever exposed, delete it on the same console page and create a new one: the old token stops working at once.

How Apify charges

A scraper on Apify is called an actor. Most of the actors Tracker uses charge per result, so the cost of a job is roughly the number of posts times the price per post.

Three limits apply at the same time, and the lowest one wins.

LimitSet where
Cap on one scrapeIn the command Claude runs
Project budgetThe project's config file
Monthly account limitThe Apify console
Part 2

Install Tracker and add your token

The quickest route is to let Claude do it. The manual route is the same four steps.

With Claude

Open Claude Code in the folder where you want the kit to live, and paste this:

Clone https://github.com/bhngyn/tracker, read its CLAUDE.md and docs/SETUP.md, and walk me through setup one step at a time.

Claude downloads and installs the kit, then stops and asks you to paste your token into the .env file. When you say it's done, Claude checks the connection and offers a small first scrape.

By hand

  1. Download and install
    git clone https://github.com/bhngyn/tracker.git cd tracker ./setup.sh # any computer: collect posts ./setup.sh --full # Apple silicon Mac: adds media, transcripts, OCR

    Run one of the two setup.sh lines. Setup creates an empty .env file in the tracker folder.

  2. Paste the token into .env

    The file is hidden in most file browsers because its name starts with a dot. On a Mac, open -e .env opens it in TextEdit. Put the token straight after the equals sign, with no spaces or quotes, then save:

    APIFY_API_TOKEN=apify_api_xxxxxxxxxxxxxxxxxxxxxxxx
  3. Check the connection

    This is free and starts no scraper.

    archive_pipeline/.venv/bin/python check_apify.py token OK account: yourname plan: FREE this month: $0.00 used of $5.00 ($5.00 left, resets 2026-01-31)
  4. Choose where your data will live

    Pick a folder outside tracker, such as an external drive. Metadata needs very little space. An archive with video can need hundreds of gigabytes.

If the check saysDo this
APIFY_API_TOKEN is not setThe .env line is empty or malformed. Repeat step 2.
Apify rejected the token (HTTP 401)Copy the token again. Look for a stray space or quote mark.
Could not reach ApifyCheck your internet connection or VPN.
Part 3

Working with Claude

Open Claude Code inside the tracker folder. Claude reads the kit's rules automatically, so you can describe what you want in plain language.

Things to ask

Check my Apify setup and tell me how much budget I have left this month.
Collect the last 500 Instagram posts from these three accounts: … Keep it under $5 and save everything to ~/research/project-a.
Get the full X history of @example_handle since 2020. Estimate the cost first.

A good request names the accounts, how many posts or how far back, a spending limit and where to save. If you leave one out, Claude asks.

What a session looks like

YouCollect the last 200 posts from @example_account on Instagram.
ClaudeThat is about 200 posts at roughly $0.0023 each, so around $0.46. I'd cap the run at $1. You have $17 left this month. Where should I save it, and shall I go ahead?
YouYes. Save it to ~/research/example.
ClaudeDone. 200 posts saved, dated 3 March to 12 November, for $0.44. Nothing failed. The file is in ~/research/example/data/raw.

Claude will always

  • Tell you the target, the estimated cost and the cap, and wait for your yes before any paid scrape
  • Run scrapes only through the kit's capped scripts
  • Keep projects and data outside the tracker folder
  • Report what was collected, what it cost, and anything cut short

Claude will not

  • Ask for your token, read it back or print it
  • Raise a budget or restart a paid scrape without asking
  • Try to get past logins, private accounts or blocks
  • Treat a partial result as complete
Your approval covers one scrape. Claude asks again for the next one. These rules live in the kit's CLAUDE.md file. They guide Claude; the hard limits are the caps in the scripts and your monthly limit on Apify.
Part 4

Projects, results and good practice

What Claude creates for you, what you end up with, and what to keep in mind.

A project

Each piece of research is a project: a small folder with one settings file, plus a data folder. Claude creates both.

~/research/example/ project.toml accounts, budgets watchlist.json optional: names to flag /Volumes/Drive/example_archive/ raw/ results + run records instagram/ … media (full install) OPEN ME.html review kit (full install)

Spending is approved in project.toml: scrapes are refused until enabled = true, and stop at total_budget_usd.

Two ways to run

ModeYou get
Collect only
any computer		Post text, dates, engagement and links, as JSON files
Full pipeline
Apple silicon Mac		The above, plus photos and videos, speech transcripts, on-screen text, watchlist hits, spreadsheets, and an offline review kit that opens in a browser

The full pipeline can run for hours or days on a large archive. It is safe to stop and restart: finished work is skipped.

Worth knowing

  • Results are a snapshot. Scrapers return what is public at that moment. Deleted and private posts are absent, and long histories can come back incomplete. Compare the count with the profile.
  • A scrape that hits its cap stops with what it has. That is a partial result. Claude tells you when it happens.
  • Media links expire. To keep photos and videos, run the full pipeline soon after collecting.
  • Re-running a finished scrape does nothing and costs nothing. To collect more, ask Claude for a new dataset.

Keep it private

  • The tracker repository is public. Never put project settings, watchlists, results or your .env in it.
  • Posts contain personal data. Store them securely and share them only with people who need them.

Use it responsibly

  • Collect public content only, and only what your work needs.
  • You are responsible for following the platforms' terms, Apify's terms, and the privacy law that applies to you.
